# 科创50 投资备忘录：为什么值得长期跟踪

**核心信念**：科创50 指数有可能成为"中国的纳斯达克"——这不是一句口号，而是基于国产硬科技自主可控的长期产业趋势。

今天这份备忘录，把跟踪框架、估值纪律和建仓计划浓缩成一份可执行清单。

## 一、跟踪什么：四个核心指标

1. **估值分位**：3年 PE/PB 百分位，判断贵不贵（当前 PE 196 倍，分位 95%——历史高位）
2. **盈利趋势**：有效 PE（剔除亏损股）≈163 倍，比名义值更真实
3. **资金流向**：588000 主力资金日度进出，辅助判断情绪
4. **ETF 份额**：长期资金是否在持续流入

## 四、怎么用 Canvas 跟踪

**手机端编辑器**（你正在看的这个）就是跟踪工作台：

1. 每月写一篇复盘 → 导出「同步到工作区」→ 我落盘 git 存档
2. 想改决策 → 说人话 → 我先给 diff → 你确认 → 落盘
3. 任何版本都能回滚，一年后回看"当时为什么这么判断"

**这就是长期跟踪的正确姿势**：有记录的判断才是策略，没记录的叫感觉。
